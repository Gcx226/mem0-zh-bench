# mem0 中文记忆评测：留出测试集验证报告

- 留出测试集：5 个合成用户（优化期间从未见过）× 5 会话 × 10 题（单跳/多跳/时间/更新/拒答各 2）
- 开发集：另 11 用户（zh_001–011），抽取指令在其上迭代；本集用户 zh_012–016 由同一生成器以新种子/新名字独立生成
- 被测系统：mem0 REST API（http://localhost:8888）
- 作答模型：deepseek-chat；裁判模型：Qwen/Qwen2.5-72B-Instruct
- 检索 top_k=5；baseline_holdout 运行于 2026-11-17，write_opt_holdout 运行于 2026-11-17
- 写入侧优化：自定义中文抽取指令（eval/zh_instructions.txt），经 mem0 官方 prompt 参数注入，无需改动源码
- 完整性声明：抽取指令在开发集上冻结后未再修改；两组在**同一容器检索状态**（jieba+OR 补丁恒定）下运行，唯一变量是写入侧指令

## 方法学说明与已知局限

1. **抽取召回率**按事实 token 在埋入会话后的记忆快照中是否出现计算；superseded 事实按埋入时点计入。token 匹配是近似，语义改写可能漏判。
2. **检索 recall@5**：top5 记忆中任一命中证据事实 token 即算命中；拒答题不计入。
3. **留出完整性**：抽取指令（zh_instructions.txt）在开发集 zh_001–011 上迭代冻结后，未依据本集任何结果修改；本集用户由同一生成器以新随机种子（index×7919）与新名字独立生成，优化期间从未出现。因此本集提升可归因于指令的泛化能力，而非对特定题目的过拟合。
4. **变量隔离**：两组在同一个容器、同一检索状态（jieba 分词 + OR 匹配补丁均已部署且恒定）下运行，唯一差异是 add 调用是否携带写入侧指令。检索侧不是本实验的变量。
5. **裁判校准**：沿用与开发集相同的裁判提示词（非拒答题答不知道判错、时间语义等价判对、核心信息即可），跨集可比。
6. **抽取非确定性**：mem0 抽取 LLM 偶发对整段会话返回空，单次运行存在噪声；本集为单次全量运行，未做 n 次重复取均值，个别题目得失含运气成分。
7. **样本规模**：5 用户 × 10 题 = 50 题（拒答 10 题不计 recall），统计效力有限，结论为方向性验证而非精确效应量估计。
